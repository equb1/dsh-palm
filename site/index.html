架构

一条协议，两种引擎

UI 不直接碰引擎。轻引擎走进程内调用，完整引擎走 WebSocket 桥；两边实现同一套会话、审批和工具协议，共用工作区。

UI React Native App 只认协议，不关心引擎
默认 LocalEngineClient LightHost · TypeScript · 进程内 300ms · 无 WebSocket
流式 / 工具 / 文档 / 生图会话、审批、提问本地完成
按需 EngineClient · WS 单文件桥 :8788
proot · dsh web :8787 Ubuntu 24.04 · Node 24 · Python 3.12 真 Linux · Office / 后台任务
HostServiceAndroid 前台服务 → proot / Node / 桥
共享工作区<filesDir>/workspace ↔ /root/work
原生能力分享 / 通知 / 相机 / SecureStore

proot 冷启动约 14 秒，空闲会回收；轻引擎目标 300ms 内就绪。密钥与 ~/.dsh 放在 rootfs 外，换镜像不丢。细节见 docs/TECHNICAL.md。

边界

先说清楚不做什么

锦囊是正在迭代的 Android 宿主。下面这些边界比宣传语更重要。

Android 优先

当前聚焦 Android arm64；iOS 尚未支持。

完整引擎有成本

proot 冷启动约 14 秒、常驻内存较高，空闲会回收；它不是默认路径。

局域网还未加密

LAN 发现与重连已可用；端到端加密、relay / WebRTC 仍在路线图。

文档能力有边界

PDF 解析与生成暂缓；旧 .doc / .ppt、render / recalc 需要桌面端或后续能力。

插件不是全量可跑

兼容矩阵给出运行方式；L1 未完成、L2 无独立运行时、L4 依赖电脑。

非官方项目

与 DeepSeek 无隶属关系；DeepSeek Harness 及相关名称归其权利人所有。
