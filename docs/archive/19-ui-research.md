# 19 · dsh-go UI 调研与差距

> 2026-11-02 调研。对象是 [dsh-go](https://github.com/ccch1mneyyy/dsh-Go)（Flutter，`main` 分支）。
> 目的：为「锦囊」整个 UI 改造定骨架、交互和视觉基线。
> 结论先说：**骨架抄它（无 Tab、聊天为主、抽屉 + 页面栈），细节挑着抄，视觉 token 直接用。**

## 一、骨架

```
LaunchLayer（启动层，覆盖全 App）
  └ RootGate（splash / onboarding / home 三选一）
       └ HomeShell = 聊天页 + 左侧抽屉（跟手拖拽；≥840dp 变 rail/sidebar）
            └ 抽屉底部 IdentityBar：主机条 / 全部功能 / 设置
                 └ 设置是压在聊天上的页面栈（二级、三级继续 push）
```

- **没有底部 Tab**。聊天是主界面，历史在抽屉里。
- 抽屉由单个 `AnimationController` 跟手拖拽，遮罩和内容分层重建，底下聊天不重建。
- 设置不是抽屉内页，是**页面栈**；长按齿轮直达设置搜索。
- 启动层与系统启动图**逐像素对齐**，首帧回调 `ready()`（可等引擎 running）才淡出，可点击跳过。
- 引导 6 步：welcome → runtime（本机/远程）→ appearance → access → apiKey → finishing。
  只有「有运行环境」是硬门槛；主题、权限、账号都能跳过或稍后。**解包等待期间穿插可并行的选择**。

## 二、聊天页

**结构（上→下）**

```
浮动顶栏：44 ≡ ｜ 标题胶囊（15 标题 + 11 状态点）｜ 模型胶囊 ｜ 新建
消息区：720 阅读列，左右 16
底部：错误/余额横幅 → 权限胶囊 → DockStack → 插件胶囊行 → Composer
浮动：回到底部键（44）、`/` 面板（与输入条同宽）
```

**Composer**：28 圆角；1–6 行自增高；两颗 **40 圆键 + 四周 8 = 单行正好 56**；
占位随状态改写（「生成中 · 可直接插话」）；右键四态（停止/麦克风/发送/语音停止）；
长按发送出「插话 / 中断并发送 / 排队」；Enter 换行、⌘/Ctrl+Enter 发送、双击 Esc 停止。

**消息渲染**

| 元素 | 形态 |
|---|---|
| 用户 | 右对齐软气泡 20 圆角、82% 宽；乐观态 72% 透明 + 发送中/插话中/排队中 |
| 助手 | **无气泡无头像**，思考 → 正文 → 「已中断」→ 操作行 |
| 思考 | 一行胶囊 + 流式时最多 3 行实时窗（只跟最新字上滑）；结束收成「思考 · 首行预览」 |
| 工具 | 32 高单行；连续 ≥3 次合并「执行 2 条命令 · 读了 3 个文件」；跑/等审批始终外露 |
| 整轮 | 正常结束收成「✓ 已完成 · 7 次工具调用」；被停/出错不折 |
| 审批/提问/产物 | 共用 ChatCard（20 圆角、16 内边距、警示色细线）；主色只给「允许本次」 |

**流式与长列表**：32ms Timer 合并增量；稳定 key 行缓存；两段 Sliver + center 锚定；
贴底同帧追到底、下拉立即取消；离底 160 出回底键、回 24 内消失；不裁最近 N 轮，
靠惰性构建 + 距顶 800 预取。

**模型/命令/附件**：顶栏模型胶囊 → 玻璃弹层（渠道条 40 / 模型卡 / 思考档 SegmentedPill 40 / 管理模型）；
`/` 在输入条上方浮同宽面板；`@` 引用文件；附件全在 ＋（相册/拍照/文件/生成 + 本对话设置）。

## 三、设置页

顶部：搜索胶囊 + 概览卡（账号/Key + 余额，底栏引擎状态）。

| 组 | 行 |
|---|---|
| AI | 模型 / 权限 / 个性化 |
| 能力 | 手机操控 / 联网搜索 / 图像与视频 / 插件 |
| 外观 | 主题 / 对话字号 / 完成后收起过程 / 宠物 |
| 通用 | 界面 / 语言 / 通知 / 语音输入 / 性能 / 后台运行 / 系统权限 / 隐私与分享 |
| 主机 | 本机引擎 / 远程主机 / 引擎参数 |
| 帮助与关于 | 使用帮助 / 社区 / 诊断 / 关于 |

行样式：`16 | 32 圆盘图标（组色）| 12 | 标题 15 | 右值 | ›`；单行 52、带副标题 64；
**右侧永远显示当前值**，比默认更宽松的值自动转 warning 色；一组一个色相；行间不画线（2px 缝）。

## 六、与「锦囊」的差距

现状：9 个组件、约 3.7k 行（`app/src/ui/`），深色单主题，聊天是列表 + 气泡。

| 维度 | 锦囊 | dsh-go | 工作量 |
|---|---|---|---|
| 骨架 | 首页 + 抽屉 + 设置 | 同 + 全部功能页 | 中 |
| 启动/引导 | 只有启动进度 | 启动层 + 6 步引导 | **大** |
| 聊天 | 气泡 + 工具行 + 审批/提问 | 思考实时窗、工具合并、整轮折叠、Dock、`/`、`@`、发送方式 | **大** |
| 设置 | 平铺卡片 | 6 组 IA + 右值 + 搜索 + 二级页 | 大 |
| 引擎 | 设置里一张卡 | 独立页（状态环/启停重启/日志/失败修复） | 中 |
| 文件/终端 | 无 | 有 | 大（后置） |
| 视觉 | 深色一套 | 深浅 + 6 主题 + 字号档 + 动效表 | 中 |
| 动效 | 基本没有 | 全套 | 中 |
| 会话管理 | 列表 + 标题搜索 | 置顶/文件夹/筛选/长按菜单/整页搜索 | 中 |

## 七、施工顺序（3 批，每批上真机看一次）
