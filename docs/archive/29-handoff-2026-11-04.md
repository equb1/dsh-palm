## 1. 这一轮完成了什么

### 1.1 输入区 / 模型 / 权限

- Composer 按 dsh-go 几何：单行 56 / 28 圆角 / 40 圆键，`+` + 输入 + 发送/停止。
- 权限与锦囊移到输入框上方；模型回顶栏，首页/聊天页都有模型胶囊。
- 权限语义：仅可查看 / 工作区内修改 / 完全权限；完全权限有二次风险确认。
- `+` 是输入框上方的四格附件面板，不是底部抽屉/宫格。
- 模型面板只做模型 + 推理等级，不带权限/工作区/说明。
- 缓存模型 id 非法时回退宿主默认（修复恢复旧缓存 `flash` 导致 1 秒出错）。

### 1.2 聊天渲染

- `ui/chat/*` 拆分：`TurnView` / `ApprovalCard` / `JumpButton`。
- 完成回合收成“已完成，用时 …”摘要；展开显示思考/工具行；工具行可展开 detail。
- 完成回合始终渲染 approval 卡；历史审批不再从日志 seed 成 pending。
- 回到底部按钮 + 生成中脉冲；去掉了 35% 视口高的 footer 空白。
- 长思考：
  - thinking 按 block 展示，只有最后一个 streaming block 是“思考中”；
  - 展开限高 320 + 内部 ScrollView；
  - live 时只渲染最后 2000 字并自动跟底，结束后看 12000 字；
  - 空 thinking 不渲染；前缀相同的 thinking 合并。
- Markdown：stable/tail 拆分，tail 逐帧解析；`prefixMatch` 对空字符串返回 false（修复新 text block 被吃掉、正文不流式）。

### 1.3 流式 / 状态

- 实时 delta 按帧合并（官方 DSH 也是按帧合并，不是每 token）。
- `flushDeltas` 优先只处理活跃 turn；历史 turn/block 引用不动；列表 preview 300ms 限流。
- `run.started/finished` 同步 sessions；`refreshSessions/session.updated` 收口 detail，列表/详情一致。
- 切会话用 `overlayLiveTurn`：同 run 的 live 回合直接替换快照回合，不再按 block 内容拼。
- bridge `startFollow` 同会话重开保留 `liveTurn/liveStep/blockIdByIndex`，切回来 mid-stream delta 不再丢。
- tool/call 带 `callId`，实时参数用 `summarizeToolArgs` 处理对象/JSON；tool 合并优先 done/非空 summary。
- 审批：删除 `seedPendingQuestions` 调用，pending 只来自 live `pendingEvents`；`questions.answer` 成功清 pendingQuestions + pendingEvents；历史只有不再 pending，没有只读卡。

### 1.4 部署

- bridge 源码：`engine/src/real/{server,project,dshClient}.ts`
- 打包：`node scripts/build-bridge.mjs` → `dist/dsh-palm-bridge.cjs` + APK asset
- APK：`cd app/android && .\gradlew.bat assembleDebug`
- 安装：`adb install -r app\android\app\build\outputs\apk\debug\app-debug.apk`
- 注意：APK 启动时 `ensurePatch` 会用 APK asset 覆盖 rootfs bridge；改 bridge 必须重打 APK，不能只 push rootfs 后重启 App。
- 当前 APK 使用本地 debug keystore，`install -r` 可覆盖；不要再卸载。

- 不要在 App 正在跑长任务时 `force-stop`；会打断回合。
- 切会话/重进时先看 `PITFALLS.md` H7 和 `STREAMING-FIX.md`，不要重新引入内容前缀合并。

## 6. 验收基线

- 新会话发 20+ 分钟任务；
- 思考中展开：继续流式（最后 2000 字），限高滚动，不撑外层；
- 输出中切会话再回：不卡、不丢 delta、不出现正文夹在思考；
- 工具行有 summary，不出现空 websearch；
- 审批：回答后重进不再出现；真 pending 才显示；
- 完成后：一个“已完成”、用时、列表 idle；
- `adb logcat -s ReactNativeJS` 无 duplicate key / OOM。
