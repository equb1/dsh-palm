## 4. 关键命令与技巧

```bash
# 无线 adb（端口会变）
adb mdns services
adb connect 192.168.1.2:<port>
adb reverse tcp:8081 tcp:8081
adb reverse tcp:8799 tcp:8799

# Metro（Windows 上改完 JS 必须重启，否则吃旧 bundle）
cd app && $env:CI="1"; npx expo start --port 8081 --clear
adb shell am force-stop cool.cnb.dshpalm
adb shell am start -W -n cool.cnb.dshpalm/.MainActivity

# 中文 IME 会改写 adb input；验 UI 前临时禁用
adb shell ime disable com.google.android.inputmethod.latin/com.android.inputmethod.latin.LatinIME
# 验完恢复
adb shell ime enable com.google.android.inputmethod.latin/com.android.inputmethod.latin.LatinIME

# mock 模型（docs 计划会依次 create_xlsx/create_docx/generate_image/read_xlsx/read_docx）
$env:MOCK_PLAN='docs'; $env:MOCK_IMAGE_MODE='url'
node --import tsx scripts/mock-model-server.ts 8799
# 轻引擎 base=http://127.0.0.1:8799/v1 model=mock key=mock
# image base 同上，model=mock-image

# release
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
cd app/android && .\gradlew.bat :app:assembleRelease
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\37.0.0\apksigner.bat" verify --print-certs app/build/outputs/apk/release/app-release.apk

# CNB release 资产上传（脚本未入库）：先 POST …/releases/<id>/asset-upload-url
#   body {asset_name, overwrite, size, ttl}；PUT upload_url；POST verify_url
```
