## 2. 桌宠实现细节

### 2.1 数据

- `app/assets/pets/<role>/pack.json`：16 个 animation（12 态 + 4 reaction），
  `frames` 每帧 ms、`cols=8`、`frameW/H=128`；
- `app/assets/pets/<role>/sheets/*.png`：8 帧横排，1024×128；
- 原生用同一份 pack/PNG 复制到 `app/android/app/src/main/assets/pets/`（34 个文件）。

### 2.2 运行

- `PetStateMachine`：12 态、tiers、60s 睡眠、wake、idlePool、reaction、瞬态 done/error；
- `PetRuntime`：按 `frames[].ms` 推进，loop/one-shot，超大 delta 截断；
- `PetCanvas`：RN 用 `View` 裁切 + `Image` 偏移，按帧 setState；
- `FloatPetService`：原生 `Handler` 帧循环，`Bitmap.createBitmap` 裁帧，
  `BitmapDrawable.paint.isFilterBitmap=false`；EdgeSnap/震动/气泡沿用。

### 2.3 测试

- `test/pet-runtime.test.ts`（6）
- `test/pet-state-machine.test.ts`（6）
- `npm run typecheck` 通过；`npm run verify` 330 / 329 pass / 1 skip。
