## 1. 本轮已完成

### 1.1 手机 / 电脑会话彻底分开

- `app/src/state/sessionList.ts`
  - `SessionSource = 'phone-light' | 'phone-proot' | 'computer'`
  - `SessionRow extends SessionSummary { source, engine }`
  - `mergeSessionRows(current, currentSource, cachedGroups)`
- `app/src/state/store.ts`
  - `sessionCache: Record<SessionSource, SessionSummary[]>`
  - `sessionSource()` 按 `engineKind`（light/proot/remote）映射
  - `openSessionRow(id, source)` 按来源切引擎：
    - computer → `remoteHost.url` 重连
    - phone-proot → `switchEngine('full')`
    - phone-light → `switchEngine('light')`
  - 旧 `sessionCache.full` 无法区分 proot/remote，迁移时直接丢弃。
- `SessionDrawer.tsx`
  - 顶部「手机 N / 电脑 M」tab；
  - 行标签 `📱 轻` / `📱 完整` / `💻 电脑`；
  - 长按菜单只对当前来源开放。

### 1.2 工作区按 tab 展示

- `workspaceCache: Record<SessionSource, Workspace[]>`；
- `refreshWorkspaces()` 按当前 source 写缓存；
- 连接时优先用 `caps.workspaces`，没有再走 `workspaces.list`；
- 抽屉按 tab 从对应缓存展示；
- 电脑 caps 没工作区时，用电脑会话的 workspace 名回退（不再显示 UUID）；
- `workspaces`/`workspaceCache` 写入 UI cache，重启后保留。

### 1.4 局域网扫描 / 远程连接

- `LanDiscovery.kt`
  - 同时探 `8788/8787`；
  - TCP 通后 `GET /health`，只接受 `{"bridge":"real"}`，排除 mock；
  - Wi-Fi IP 优先，排除 VPN 198.18/蜂窝；
  - 跳过手机自身 IP；
  - 同一 host 只保留一条，8788 优先。
- `store.connect()` 远程 `autoReconnect:true`；

- 旧缓存 loopback remoteHost 读取时丢弃。

### 1.5 「在电脑继续」（复制历史）

`store.pushSessionToComputer(logicalId)`：

1. 取当前会话 detail；
2. `buildHandoff` + `buildSeedText` 压历史；
3. 必要时 `connect(remoteHost.url)`；
4. 电脑 `sessions.create` 建真实会话；
5. `sessions.send` 发 seed；
6. `refreshSessions()`。

UI：抽屉会话菜单「在电脑继续（复制历史）」，带二次确认。

**注意**：这是复制/接管，不是实时双向同步；电脑上会新增一条会话，之后两边独立。

## 4. 关键坑

1. **Metro 缓存会让 release 打旧 JS**
   - 现象：源码改了，APK 仍旧逻辑；
   - 处理：`npm run release:android`；或手动删
     `%TEMP%\metro-cache` + `app/android/app/build/generated/assets/react/release`。
2. **无线调试端口每次变**
   - 手机「无线调试」显示的端口才是连接端口；
   - 配对用 `adb pair <ip>:<pairPort> <code>`，再 `adb connect <ip>:<connectPort>`；
   - 端口可能被 WSL/虚拟网卡干扰，优先 `192.168.x.x`。
3. **ColorOS `Settings.canDrawOverlays` 误报**
   - AppOps 已 allow 但 Settings 返回 false；
   - `HostModule.canDrawOverlays()` 已用 AppOps 兜底；
   - 仍不行时手动开「显示在其他应用上层」。
4. **外置模式单宠物是产品取舍**
   - 开启后 App 内宠物隐藏，只保留原生；想要“App 内 RN + 桌面原生”需再做可靠前后台切换。
5. **自动化点击坐标**
   - 设备 1272×2800；先 `uiautomator dump` 拿 bounds，不要按预览图坐标点；
   - 抽屉/分享面板/悬浮窗容易抢触摸。
6. **Gradle pet assets**
   - 源目录是 `app/assets/pets`，生成目录 `build/generated/petAssets/pets`；
   - 不要再手动复制到 `src/main/assets/pets`。
