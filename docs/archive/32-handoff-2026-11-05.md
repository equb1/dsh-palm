## 4. 关键命令与技巧

```bash
# 无线 adb（端口会变）
adb mdns services
adb connect 192.168.1.2:<port>
adb reverse tcp:8081 tcp:8081
adb reverse tcp:8799 tcp:8799

# Metro（Windows 上改完 JS 必须重启，CI 模式不热更）
cd app && $env:CI="1"; npx expo start --port 8081 --clear
adb shell am force-stop cool.cnb.dshpalm
adb shell am start -W -n cool.cnb.dshpalm/.MainActivity

# 输入：中文 IME 会改写 adb input；长文本分块 + %s 代替空格最稳
adb shell input text "Create%sa%sdocx"
# 验完恢复 IME
adb shell ime enable com.google.android.inputmethod.latin/com.android.inputmethod.latin.LatinIME

# 生成文件 / 分享证据
adb shell uiautomator dump /sdcard/ui.xml
adb pull /sdcard/ui.xml scratch/ui.xml

# 上传测试文件到 Download（中文/#/% 名先推临时名再 mv，避免 adb push 把 # 当注释）
adb push scratch/uploads-test/测试\ 报告#1%.pdf /sdcard/Download/tmp.pdf
adb shell "mv /sdcard/Download/tmp.pdf '/sdcard/Download/测试 报告#1%.pdf'"

# release
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
cd app/android && .\gradlew.bat :app:assembleRelease
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\37.0.0\apksigner.bat" verify --print-certs app/build/outputs/apk/release/app-release.apk
```
