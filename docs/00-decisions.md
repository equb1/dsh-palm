# 决策台账

> 每一条都是讨论后定下来的。改任何一条之前，先看"理由"和"被否掉的选项"——那些选项当时为什么不选，通常改主意时会重新踩一遍。

| # | 决定 | 理由 | 被否掉的选项 |
|---|---|---|---|
| D01 | 手机是**完整宿主**，不是遥控器 | 遥控器在电脑关机时变砖；且手机独有的能力（相机、分享菜单、随身）在遥控模式下全部浪费 | 纯远程客户端（赛道已有 3–4 个成熟项目） |
| D02 | 电脑是**可选的对等体**，不是上游 | 单人开发要能活到发布，不能一开始就背双端联调的复杂度 | 客户端/服务端的父子关系 |
| D03 | 跨设备**只同步身份与会话索引**，不同步文件与执行 | 工作区同步是所有多端 agent 的坟场：文件大、冲突多、权限乱 | 全量工作区同步；云端文件系统 |
| D04 | 会话**单 writer**，其他设备只发指令 | 避开并发、锁、一致性，直接复用 DSH 的 `steer` 语义 | 多端同时编辑（需 CRDT） |
| D05 | 跨宿主取文件用**引用 + 委派**，不复制 | 文件只有一份，住在原本的宿主上；引用是可撤销的 | 复制/镜像文件 |
| D06 | 委派必须**双向** | 只有手机调电脑，仍然是主从；电脑调手机的相机才是真正对等 | 单向委派 |
| D07 | **任何跨设备能力必须有本地降级路径** | 守住"分开"这条性质，否则退化成遥控器 | 无降级（连不上就报错） |
| D08 | 连接用**设备配对**，不做云端账号 | 连起来这件事本身不引入外部依赖；删配对即回到完全独立 | 云端账号体系 |
| D09 | 工作区 = **能力契约**，在工具注册层执行 | prompt 里写"请不要用 shell"是安全剧场；看不见工具才是真的 | 提示词约束 |
| D10 | 能力契约的粒度是**会话**，不是工作区全局 | 切换预设等于切换整个世界太重，会话列表和记忆都会断 | 一个工作区一个 profile（作为过渡方案保留） |
| D11 | 预设分**三级**：L1 声明式 / L2 技能包 / L3 代码插件 | 手机端装任意代码 = 把风险装进用户口袋；先用零代码的 L1 建生态 | 一上来就开放 npm 插件市场 |
| D12 | v1 **只内置有限预设**，不开市场 | 一个人的注意力是最稀缺资源，做平台方会把自己拖死 | v1 做插件市场 |
| D13 | 前端用 **RN + Expo prebuild（CNG）**，不用 Expo Go、不用纯托管 | 团队熟悉 RN；EAS 提供无 Mac 的 iOS 构建与 OTA；原生部分本来就免不了 | Kotlin/Compose（无法覆盖 iOS）、Flutter（要学 Dart）、Expo 托管（原生模块跑不了） |
| D14 | **引擎是独立进程，UI 是纯客户端** | UI 可换、逻辑可单测、引擎崩溃不带走界面 | 逻辑写在 UI 层 |
| D15 | 每个平台的**原生代码 ≤ 1500 行**，只做七个接口 | 防止退化成"用 RN 写的 Android 应用"，跨端优势归零 | 让原生承担业务逻辑 |
| D16 | 难活交给本地 Node，**但仅限宿主侧** | SSH/crypto/转换在 Node 里最省力；iOS 没有 Node，客户端必须纯 JS | 客户端侧也依赖本地引擎 |
| D17 | **iOS 只做遥控器**，定位是纯 JS 客户端 | 没有 `fork`/`exec`，本机引擎物理上不存在 | iOS 本机引擎（iSH 类方案） |
| D18 | **鸿蒙最后做**，不参与当前选型 | 三种栈都没有"一套通吃"，鸿蒙对谁都是另起一摊 | 用鸿蒙决定技术栈 |
| D19 | 采用 **Expo prebuild 生成的 `android/`**，自定义代码放 `modules/` | 保持 CNG 可重建；升级 SDK 时少踩 config plugin 的坑 | 手改 `android/` 根目录 |
| D20 | 命名：对外**锦囊**，对内 **`dsh-palm`** | 双层职责：品牌负责被记住，技术名负责血缘与场景 | 单层命名（`dsh-go` 已被占，`-mobile`/`-pocket` 同样已占） |
| D21 | v1 **不做推送**，用前台服务 + 本地通知 | 事件发生在自己的机器上，本地通知零成本；远程推送留到 v2 | v1 接第三方推送 |
| D22 | rootfs **分层、只在 CI 构建**，手机只下载校验解包 | 引擎能独立发版，不用等商店审核；可回滚 | 全量塞进 APK；手机上构建镜像 |
| D23 | 可写状态（`$HOME`、会话、工作区）**永远在层之外** | 换层不动数据；基础层约定只读，插件写不坏系统 | 把数据放进 rootfs |
| D24 | v1 运行时选**精简 rootfs**，不做"原生 node + toybox" | 后者要改引擎对 POSIX 的假设，一个人别碰 | 完整 rootfs（太大）；纯原生 node（太费工） |
