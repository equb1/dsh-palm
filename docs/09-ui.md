# 09 · 界面语言

> 对齐 DSH 官方网页版与 dsh-go 的视觉，不是另起一套。
>
> 一句话：**近黑底 + 半透明玻璃层 + 胶囊形状 + 蓝色交互色**。

## 为什么不是自创一套

用户从官方网页版过来，认的是同一套视觉。自创一套的结果是"看起来像个第三方套壳"——而我们恰恰要在"这是正经客户端"这件事上建立信任。

所以规则是：**新组件先问"官方/Dsh-go 里长这样吗"，再问"好不好看"。**

## 颜色

| 用途 | 值 | 说明 |
|---|---|---|
| 背景 | `#0A0B0F` | 近黑，不用纯黑（纯黑配白字太硬） |
| 玻璃层 | `rgba(255,255,255,0.045)` | **层次全靠叠这个，不用阴影** |
| 玻璃层·强 | `rgba(255,255,255,0.075)` | 头像底、按钮底 |
| 描边 | `rgba(255,255,255,0.075)` | hairline，永远不要实线 |
| 正文 | `#E9EBEF` | |
| 次要 | `#9AA3B2` | 工具行、说明 |
| 弱 | `#6B7385` | 时间、元信息 |
| 交互 | `#6C8AF0` | 发送、批准、运行中 |
| 品牌 | `#D8A94B` | **只用于品牌标识**（锦囊的"锦"） |

**蓝色是"可以点"，金色是"这是我们"。** 两者不混用——金色不用于按钮，蓝色不用于 logo。

## 形状

- **胶囊（999）**：所有顶部控件、状态标签、输入框容器
- **20**：卡片、气泡、审批卡
- **12**：内嵌代码块
- 圆形按钮：36 / 34

没有直角，没有大阴影，层次靠"叠一层半透明白"。

## 排版

| 层级 | 字号 | 用途 |
|---|---|---|
| 正文 | 15 / 行高 25 | 对话内容 |
| 标题 | 14–15 / 600 | 会话标题、卡片标题 |
| 次要 | 12.5 | 摘要、说明 |
| 元信息 | 10.5–11 | 时间、步数、token |
| 等宽 | 11.5–12 | 命令、路径、工具名 |

中文不用 letterSpacing，英文和数字可以用一点点。

## 几个固定结构

### 顶部

```
[‹]  [标题 · 状态]  [预设]  —————  [✎]
```

标题和状态在同一个胶囊里上下排，状态用一个小圆点 + 两个字（生成中 / 就绪）。
右侧留白把"新建"推到最右——不是靠 space-between，而是插一个 `flex:1` 的占位，这样中间宽度变化时不会跳。

### 首页：一个输入框，预设是一排胶囊

参考 Gemini / 豆包 的首页结构：

```
        需要我做点什么？
      下面选一个锦囊，或者直接说

  最近
  ─────────────────────

 ┌─────────────────────────┐
 │ 给锦囊发消息…        [↑] │
 │ [文 文档助手][票 票据]…  │
 └─────────────────────────┘
```

**预设不做弹层。** 豆包和 Gemini 的能力入口都是输入框里的一排小胶囊——扫一眼就能换，不用先点开再看。

- 输入区固定两行：上排输入 + 发送，下排是锦囊胶囊
- 选中态：`blueSoft` 底 + 蓝字；未选中：半透明白 + 灰字
- 会话页用同一排胶囊，切换走 `sessions.setPreset`，能力契约跟着换
- 胶囊横向可滚，预设多了也不会挤在一起

> 早先做过「整屏底部抽屉」，被否掉了：一屏只放三个选项，太重，而且每次换预设都要开合一次。胶囊是常驻的，零次点击。
### 消息

- 用户：右对齐气泡，`rgba(255,255,255,0.08)`，最大 84% 宽
- 助手：**不加气泡**，直接落在背景上
- 思考：`✳ 思考 · 首行…  ▾`，一行，点开才展开
- 工具：`▤ 工具名  摘要  ✓`，运行中蓝点，完成灰勾
- 回合尾：`42 秒 · 4 步`，10.5 号，最弱

### 审批卡

一张卡里必须有四样，缺一不可：

1. 标题（将要发生什么）
2. 命令原文（等宽、深底）
3. 影响摘要（人话）
4. diff（`+` 绿 / `-` 红）

按钮：`拒绝`（描边）、`批准`（蓝色实心）。**批准永远在右边**——这是肌肉记忆。

### 输入框

```
[+]  [占位文案]  [↑]
```

运行中，占位文案变"生成中 · 可直接插话"，右侧圆钮变方块（停止）；一旦开始打字，方块变回 ↑（发送即插话）。

## 已知取舍

- **不用图标库**：目前用字符（‹ ✎ ☰ ↑ ■ ▾），零依赖但字形在不同系统上会有差异。等确定要做原生，再换成矢量图标。
- **不做毛玻璃模糊**：RN 没有原生 backdrop-filter，用"半透明白 + 深底"模拟。真正的模糊要等 expo-blur 进依赖。
- **金色只做点缀**：品牌识别靠那颗"锦"字圆标 + 桌宠，不靠大面积配色。
